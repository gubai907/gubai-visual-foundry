# Brand Profile Example — Fictional

这是匿名结构示例，不代表真实品牌，也不作为任何任务的默认值。

```text
profile_id: example-lifestyle-accessories
brand_name: Example Brand
revision: 1
source_of_truth: project brand brief
market: supplied by project
audience: supplied by project
positioning: accessible everyday accessories
brand_tone: calm, useful, personal
channel_rules:
  PDP: prioritize product structure, scale and contact
  social: allow one lifestyle action while preserving product clarity
palette: read from approved brand assets
text_logo_rules: use exact supplied assets only
model_template_namespace: optional project-local namespace
known_failures: record only observed failures
unresolved_rules: hold_for_source_review
```

使用时替换全部示例值。不要把 Example Brand、accessible、calm 或任何字段当成通用视觉默认值。
