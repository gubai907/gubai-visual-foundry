# Fashion

触发：用户需要时尚杂志、服装 editorial、lookbook、fashion campaign、街头生活方式或时尚妆造。以衣着/人物表达为专业目标，仍遵守所有参考角色与硬 Lock。

## 模式选择

| 模式 | 视觉任务 | 控制重点 |
|---|---|---|
| editorial | 一张图表达一个明确的编辑观点或画面关系 | 有意裁切、人物与空间、克制视觉实验；不强制“冷脸” |
| beauty | 时尚语境里的妆容/面部特写 | 妆色层次、自然皮肤、眼唇读取；不改骨相 |
| lookbook | 读清服装完整廓形、搭配和鞋 | 稳定机位、自然比例、完整衣着；少遮挡主衣 |
| campaign | 系列品牌视觉和服装记忆点 | 一个主视觉命题，品牌 profile 决定语气，不默认奢侈品 |
| street/lifestyle | 穿搭融入可拍摄的日常动作 | 空间尺度、步态、重心、衣料运动、自然光源 |
| styling/makeup | 设计用户授权变化的造型或妆容 | 只释放指定衣着/妆发字段，不继承风格参考整套身份 |

## 专业前缀

只有用户要求专业角色前缀且任务属于杂志时尚时，Prompt 可开头写：
“以国际时尚杂志摄影师与视觉总监的专业标准组织本画面，准确呈现已锁定的人物与衣着，建立清晰的编辑意图。”
这是创作角色提示，不冒称真实摄影师拍摄或刊物背书。非杂志任务不自动使用；refine 模式不使用。

## Pose Grammar

先定义身体支撑点与重心，再写躯干方向、肩胯关系、手臂走向和一个主要动作。一次只选一个主要姿态；避免互相冲突的“走动同时端坐”。
与包/手机/眼镜接触时加载 Prop Lock，写出谁支撑谁、如何握持/佩戴、遮挡和受力。姿态应服务衣着与关键对象读取，不为时尚效果扭断手腕或掩盖商品。
Style Reference 只贡献被允许的姿态语法；已锁姿势时只取未锁构图/情绪，不强行照搬。

## Natural Expression / Gaze

用明确而轻微的状态：放松下颌、眉间自然、嘴唇轻合或符合情境的微笑；眼神有一个合理注视目标（镜头/物体/画外方向）。不同时写凝视镜头与看向远处。
保留身份、自然不对称与眼睑结构；眼神光服从光源，不靠放大眼睛、夸张锐化或浓妆制造存在感。自然不等于统一冷漠、闭眼或假笑。
用户指定夸张表情时执行其表达意图，仍保持可信解剖。

## Body Proportion Control

以 Body Reference 决定头身比、肩宽、躯干腿长、肢体尺度；无身体来源时使用自然可信比例，不默认数字化“九头身”。
全身时写清机位高度和身体与相机距离，避免无意广角拉腿、缩头、细长脖颈。不可通过改变身材来模仿参考图摄影效果。
衣服是可构造的：接缝、领口、袖窿、重量、褶皱和重力方向自洽；系列鞋、妆发、配饰同样保持。

## 编译与验收

Lock → 一个编辑目的/模式 → 一套完整造型和一个动作 → 构图/摄影/光线 → 自然表情和材质 → 输出规格 → 当前风险负面约束。
若衣着被锁，造型段复述来源而非新设计。QA 使用共享九维评分，不为 editorial 放宽身份、手部、服装或道具错误。
可用负面项按需选：identity drift, altered wardrobe, oversized head, stretched limbs, stiff gaze, forced expression, hand fusion。禁止一股脑加入不适用项。
