# video-storyboard

## 生成路径

| 路径 | 适用 | 核心控制 |
|---|---|---|
| 单镜文生视频 | 无可用画面参考 | 一个动作、一个相机行为、一个信息重点、时长；不承诺跨镜同脸 |
| 图生视频 | 已有通过的静帧 | 静帧作锚点，只指定一个身体/视线/物体/相机动作 |
| 首尾帧过渡 | 起止画面均确认 | 明确起止状态和一个连续变化，不同时换场换人重构物体 |
| 相邻镜头序列 | 前一镜已确认 | 保留人物与场景连续层，只改一个动作或视线 |
| 局部视频修复 | 已生成视频只有一个明确问题 | 锁其余角色、场景、镜头、动作，只修最低分字段 |

每镜一个可见目的、一个主动作、一个信息或产品重点；写时长、相机行为和段末可见状态。多镜先给简洁镜头表，再逐镜 Prompt。
图生视频保留已确认静态锚点；首尾帧明确起止状态和可实现的连续变化，不能同时换人换场重构物体。
按任务选电影中速、品牌中密度、强钩子或慢节奏；停顿/空镜须承担情绪、读取、悬念等实际功能。不要把慢动作当默认高级感。
相邻镜头按 core/continuity 冻结人物、场景、光线和机位，只变一个动作或视线。视频检查需看时间中段，不凭首尾正确判断全段成功。
电影叙事时读取 knowledge/cinematic-realism；商业读取区和所有 Lock 仍优先。

## 节奏档位

| 档位 | 使用方式 |
|---|---|
| 电影感中速 | 较少镜头，每镜承担情绪或空间信息 |
| 品牌短片中密度 | 每镜增加明确产品/信息，动作自然 |
| 强钩子/高动作密度 | 缩短镜头，优先可见变化和清晰重点 |
| 慢节奏但信息明确 | 留白必须承担读取、关系、悬念或蓄力 |

## 镜头字段

`镜头功能 → 可见动作 → 人物/物体位置 → 相机关系 → 光线 → 产品/信息重点 → 时长 → 段末可见状态`。
段末状态必须是下一镜可生成的画面事实，不能只写“承接下一段”。

相邻镜头可用开头：

```text
Preserve the supplied previous frame as the exact character, wardrobe, prop,
location, lighting, camera-height and spatial anchor. Keep the same original
performer and emotional baseline. Change only [one named action or gaze shift].
Keep movement subtle, physically plausible and anatomically stable.
```

若上一帧同时是受保护产品实拍，继续保留 Product Lock 或 Protected Source Patch Lock。

## 视频验收

并排检查角色、发型、服装、道具状态、场景结构、主光方向、相机关系、唯一批准动作、商品结构以及肢体/衣料运动。任一连续性项目明显漂移时，不把失败帧当作新锚点；回到最后通过帧做局部修复。
