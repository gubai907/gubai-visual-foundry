# reference-translation

先按 reference-role-matrix 区分角色。本模块的原创转译边界仅作用于 Style/语法参考；Face/Product/Prop Reference 用于保留，不要求把它们“换掉”。
拆解：用途 → 裁切/构图 → 主体关系 → 色彩材质关系 → 光线方向/反差 → 环境证据 → 姿态/动作 → 情绪。
改写为可见指令，如“侧光掠过边缘、主体处于上中部读取区”；不用“高级感”替代具体关系。
不从 Style Reference 继承人物身份、产品设计、Logo、文案或整幅画面。锁定衣着不换；环境语法与精确背景保留分开。
一次可用一个实验视觉装置，仍保留清晰未失真的对象读取区。用户明确要求保留构图时按其编辑范围执行，不用旧版“必须换完整构图”覆盖当前要求。

输出前检查：能否指出迁移的是哪一种视觉语法；是否已经隔离 Style Reference 中的具体人物、产品、文字、Logo 和地点；当前品牌/渠道目标是否仍清楚。若参考图承担 Face/Product/Prop 等保留角色，则按对应 Lock 使用，不能把保留资产“原创化”。
