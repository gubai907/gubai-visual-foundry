# Identity Lock

来源身份保留或固定角色时锁：脸型骨相、眼鼻唇相对比例、肤色范围、发际线、自然发色、耳位、头颈关系和稳定识别点。不得混入 Style Reference 或 Full Body Reference 的另一张脸。
单张用户人脸来源可以是身份依据，不要求先建角色库。系列使用已批准身份母图，并记录验证过的角度；仅有文字描述不承诺同脸稳定。
衣服、背景、单次发型不属于永久身份，但系列可能单独冻结它们。
临时人物按本图原创角色描述，不创建命名资产；换人模式不继承原人物身份。hands-only/无人不输出 face 或 gaze 词。

可用句：Preserve the identity in Face Reference A: the same facial geometry, proportions, skin-tone range, hairline and identifying features. Do not blend facial traits from other references.
只写可见且有证据的特征，不臆测隐藏特征，不以审美修脸改变骨相。
