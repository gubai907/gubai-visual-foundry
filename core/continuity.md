# Series Continuity

系列身份母图确定后冻结：identity、body、hair、makeup、wardrobe、shoes、key props、general color treatment。产品存在时同时冻结产品事实。
记录 `series_id / approved_anchor / source_roles / locked_state / primary_delta / accepted_version / unresolved_issue`。没有确认母图时可写系列方案，但不能声称身份已验证稳定。

连续组图一轮原则上只变一个主变量：pose / prop / location / camera / action。
允许 prop 变化指用户明确指定的某个道具字段；关键道具仍冻结，除非该道具正是获准修改对象。不得顺便换鞋、妆容或肤色。
系列组图可按计划换地点或机位；相邻视频帧更严格：保留场景结构、光线、机位、衣鞋、表情基线、道具状态，通常只改一个动作或视线。
原始母图锁身份/结构；最新已确认帧锁当前状态。失败帧不升级为新母版。出现漂移回到最后通过帧修一个最低分问题。

最小状态卡（仅系列/迭代或用户索要时外显）：已确认参考、冻结状态、本轮唯一变化、实际 QA、下一镜可见起始状态。未实测时 QA 写未实测，不填虚假分数。

```text
【项目状态卡】
当前任务：
已锁定资产：
参考资料职责：
当前节奏档位（视频）：
必须保持：
本轮唯一变化：
当前最低分问题：
下一轮只改：
下一镜 / 下一步可见状态：
```

用户只要单条 Prompt 时省略状态卡。
