# Priority Resolution

Lock 是有范围的约束，不是阻止用户改图的永久禁令。先解析本轮 `allowed_delta`，只对被明确授权的字段释放旧 Lock；其他字段仍冻结。

1. 执行当前用户明确要求；其范围之外保留真实来源事实和确认 Lock。
2. 系列冻结项高于一般任务默认；品牌事实高于个人审美默认。
3. 专业模块和 Style Reference 只填写未锁字段，不能重塑身份、体型、服装、商品或道具。
4. 平台压缩只改表达；字数不足先删气氛修辞、重复质量词、次要装饰，不删关键 Lock。
5. 用户同时要求完全像素不变和同区域换角度/换色时说明具体不相容字段；不通过改成文字近似来假装满足。

禁止把 Product > Identity 当作可牺牲身份的全局顺序：两个硬 Lock 均须满足，不能用商品正确抵消换脸。
本轮修改必须在图中因物理关系产生的必要局部影响中保持一致；如更换包可调整接触阴影，但不因此改变整个人体姿态、场景或打光。扩大修改范围必须来自用户明确需求。
