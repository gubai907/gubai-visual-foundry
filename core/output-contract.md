# Output Contract

交付物以当前用户请求为准；语言、是否生成和详细程度从 user-defaults 补齐。
NORMAL 是一个完整、可执行的 Prompt：参考角色（如有）→ 必要 Lock → 用途与一个主要动作/场景 → 构图比例 → 摄影光线 → 材质 → 输出规格 → 相关 Negative Constraints。完整不等于长报告。
压缩输出保留关键 Lock、主要动作、主要视觉和必要禁止项；不附长分析。
所有写入 Prompt 的尺寸、品牌文案、身份依据必须有来源，未知不填假参数。

最终 Prompt 优先放 Writing Block；使用宿主支持的 standard 类型及唯一五位 id。宿主不支持时用可复制纯文本块。解释与评分留在块外。单次只要提示词时不追加默认验收清单。
视频每镜一条可执行 Prompt，包含镜头用途、动作、时长和可见段末状态；完整分镜可用表格。多个镜头按平台支持拆分，不把整支片混成一句。
修复只输出冻结项与一个局部修复目标；用户请求诊断时可附分数、证据及修改字段。未看到图时不提供图像实测评分。
生成媒体时接入当前可用生成流程并验收实际返回结果；不能把已写好 Prompt 当成已生成。不可用时准确说明可交付部分。

## 按需字段

普通单图直接给 Prompt。多参考、受控编辑、固定角色或视频任务可在 Prompt 前增加一行：
`Reference roles: [文件/图片] = [Face / Full Body / Style / Product / Prop / Environment / Text / Approved Frame]`。

只有控制边界会影响执行时，才补充“工作方式”：文生图、图生图、蒙版/局部编辑、图生视频、首尾帧、视频编辑。不要把能力说明写成长报告。

用户要完整方案时，输出可扩展为：用途/渠道、参考角色、正向 Prompt、Negative Constraints、比例；视频增加时长、镜头角色和段末状态。用户要求双语时必须给完整双语 Prompt，而不是只翻译摘要。

电影叙事任务在用户没有限定“只给 Prompt”时，可加 1–2 句画面节拍；只要 Prompt 时将节拍编入正文。
