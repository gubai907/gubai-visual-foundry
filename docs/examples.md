# 三个完整教学案例

[返回首页](../README.md) · [快速上手](quick-start.md)

以下输入与输出是为说明用法编写的虚构示范，没有对应的实测生成图或视频。输出会随实际参考图、请求与平台变化。

## 案例一：产品场景图

### 输入

```text
请使用 $gubai-visual-foundry：
为一只无品牌哑光浅灰色保温杯写电商场景图提示词。
杯子直立在浅色木桌上，窗侧自然光，比例 4:5。
保持杯身比例和杯盖结构，不加文字、标志、水滴或装饰道具。
只输出中文提示词，暂不生成图片。
```

### 提示词示范

```text
竖幅 4:5 产品场景图。一只无品牌哑光浅灰色保温杯直立于浅色木桌，
杯身与杯盖连接结构清晰，杯子完整入画，主体周围保留适度留白。
窗侧柔和自然光照亮杯身一侧，另一侧保留自然明暗过渡，桌面接触阴影符合光源方向。
背景简洁、低对比，呈现哑光涂层和浅色木纹的材质差异。
保持既定杯身比例、杯盖结构与浅灰色表面，不新增文字、品牌标志、水滴或装饰道具。
```

检查重点：主体数量、杯盖结构、颜色和材质是否符合要求。文字设定不能保证复现一个未提供参考的真实产品。

## 案例二：多参考人物与服装

### 输入

```text
请使用 $gubai-visual-foundry：
我已上传三张图。
图 A 负责人物身份；图 B 只负责服装和衣鞋；图 C 只负责构图和光线。
请写时尚全身图提示词，不带入 C 中的人物、服装、文字和道具。
输出中文，暂不生成图片。
```

### 提示词示范

```text
参考职责：图 A = 人物身份；图 B = 服装与衣鞋；图 C = 构图与光线。
以图 A 中的人物为主体，保留其可辨认的面部特征；服装款式、颜色、层次和鞋履以图 B 为准。
创作时尚全身图，人物完整入画，不裁断头部与鞋履。
将图 C 的构图关系和光线方向适配到当前人物与服装，保持主体可辨认、衣着结构清楚。
不得从图 B 引入其他人物身份，不得从图 C 引入人物、衣服、文字或道具。
避免多余肢体、手部结构错误、服装混合和鞋履替换。
```

实际使用时应先分析上传图片，再补充有依据的具体描述。这里展示的是分工方式，不代表已分析任何真实图片。生成后核对身份、服装与全身裁切。

## 案例三：连续产品分镜

### 输入

```text
请使用 $gubai-visual-foundry：
给虚构的无品牌白色香薰瓶做三镜分镜，每镜 3 秒，9:16。
保持瓶型、瓶盖、空白标签和浅米色背景一致。
分别展示整体、瓶盖细节和整体收束。
输出分镜表与每镜提示词，暂不生成视频。
```

### 分镜示范

| 镜头 | 目标时长 | 动作 | 段末可见状态 |
|---|---|---|---|
| 1 | 3 秒 | 镜头缓慢靠近静止的瓶子 | 整体瓶身仍完整可见 |
| 2 | 3 秒 | 在瓶盖近景轻微横移 | 瓶盖连接位置清楚可见 |
| 3 | 3 秒 | 镜头缓慢后退 | 瓶子完整入画，周围留白 |

### 每镜提示词示范

```text
镜头 1：9:16 产品视频，目标 3 秒。无品牌白色香薰瓶静置在浅米色背景前，
镜头缓慢靠近；保持瓶型、瓶盖、空白标签和侧面柔光，段末整个瓶身仍完整可见。

镜头 2：9:16 产品视频，目标 3 秒。沿用同一只瓶子、浅米色背景和侧面柔光，
以瓶盖与连接处为近景，镜头轻微横移，瓶子保持静止；段末瓶盖连接结构清楚可见。

镜头 3：9:16 产品视频，目标 3 秒。沿用同一只瓶子与相同背景光线，
镜头从产品中景缓慢后退；段末瓶子完整入画，周围保留简洁留白。
```

执行时按工具支持拆分镜头，目标时长需符合平台能力。确认生成静帧后，可用对应已确认帧作为每镜锚点；分镜文字本身不保证视频没有漂移。
