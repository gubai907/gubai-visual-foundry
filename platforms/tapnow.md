# TapNow Adapter

本文件定义可选的 TapNow Prompt 表达约定，不假设某版本的参数、权重或功能。
默认 COMPACT：短句、直接、减少嵌套。顺序：关键参考 Lock → 主动作 → 主视觉 → 必要禁止项。删重复画质词、长职业介绍和次要装饰；不要删身份、体型、衣鞋、产品/道具接触等适用硬锁。
角色编号必须保留清楚，不能把“同参考图”用于多张职责不同的图。无必要不附分节、分析或冗长 Negative 列表。
例：脸用图1，身材与衣鞋用图2，包用图3，全部保持；自然站立看向窗外，柔和侧光，3:4。包按原尺寸自然握持，不换脸、不改衣鞋或包、不悬浮。
NORMAL 显式覆盖压缩时保留完整内容，仍用短句。
refine 组合：先写原图身份、构图、姿势、衣物、物件、背景和光线不变，再仅列细节增强，禁止加入新场景。像素能力依实际工具核验。
