# Generic Adapter

## 任意平台适配

本适配器用于未指定平台及未配有专用规则的视觉生成、编辑或视频平台。根据当前请求、用户提供的格式与实际工具能力自行选择自然语言、分字段、正向/负向、编辑指令或逐镜头表达。

- 优先从当前请求与环境确定平台；未指定时直接输出通用提示词。
- 确定支持的参考图职责、编辑范围、输入字段与输出规格后调整表达，不改变已确认的主体事实和保护要求。
- 用户指定简短、完整或双语时遵循该形式；多镜头按平台支持拆分。
- 对尺寸、参考数量、权重、种子、时长和参数语法，只使用当前工具或可靠文档明确支持的值；没有依据时表达目标，不虚构参数。
- 实际生成使用可用工具并验收；提示词适配本身不表示平台已直连、全网实测或支持所有功能。

默认 NORMAL：明确来源角色与 Lock → 主体动作场景 → 构图比例 → 一套摄影光线 → 材质 → 当前 Negative。
用户明确简短则 COMPACT；operation=refine 优先 REFINE。不存在一个必须所有平台照搬的文本模板。
工作方式明确为文生图/图生图/蒙版编辑/视频路径。只有实际支持的能力才能承诺；文生图不能保证逐像素保留或真实同脸。
负面约束无独立入口时合并为最后一句。未知尺寸上限、参考图权重、seed、参数名不填写；执行工具前按其实际 schema 核实。
本适配器是内部编译约定，不是厂商规格说明。

## 工作方式能力边界

| 工作方式 | 可以控制 | 不应承诺 |
|---|---|---|
| 纯文生图 | 文字 Lock、原创人物与场景 | 像素级还原、跨图同脸 |
| 图生图 | 结构/构图继承、适度重建 | 大改透视后仍完全同人同物 |
| 蒙版/局部编辑 | 保护补丁、局部重建 | 蒙版边界外的未验证绝对不变 |
| 首尾帧视频 | 明确起止状态和一个连续变化 | 同时复杂换场、换人、重构物体 |
| 图生视频 | 以已确认静帧为锚点的小幅动作 | 长时段不漂移的绝对保证 |
| 视频编辑 | 局部保持与单变量修复 | 全面重构仍无缝一致 |

具体平台能力以当前工具为准；能力不明时只写目标和限制，不捏造参数。
