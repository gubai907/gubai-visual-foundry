# Quality Gate

## 两种检查

Prompt 静态检查：参考权限、字段冲突、保留范围、压缩丢锁、未授权变量。结果是通过/待修，不给虚构图像分数。
图像 QA：必须实际看到生成图和相关来源才打分。看不到来源时相关一致性写未验证；不可见/不适用写 N/A，不计为 0 或 5。视频须检视时间内变化，未检查部分标明未验证。

| 维度 | 检查证据 |
|---|---|
| Identity | 与身份来源比较骨相、五官、肤色范围、稳定特征 |
| Body Proportion | 头身比、肩躯干腿比例、头颈衔接 |
| Wardrobe | 廓形、领口、层次、面料、颜色、鞋 |
| Product / Prop | 结构、尺度、材质、五金、佩戴/握持、遮挡及接触阴影；分别记录商品和各道具，维度取最低分 |
| Hands / Anatomy | 可见手指、关节、四肢、重心、物理接触 |
| Expression / Gaze | 表情自然程度、视线目标、眼睑和光源关系 |
| Composition | 指定比例/裁切、主体位置、读取区与层次 |
| Lighting | 源方向、软硬、阴影、高光及连续性 |
| Material | 皮肤/发丝/织物/皮革/金属与边缘，无塑料或锐化伪影 |

0：完全失败或目标缺失；1：严重偏离；2：明显多处错误；3：主要意图成立但有明确可见缺陷；4：达标且仅轻微偏差；5：与所需来源/目标高度一致，无发现的相关缺陷。
分数不是生物识别结果，也不是精密测量。每项给一句可见证据；数值基于当前使用尺寸判断。

初版门槛（可由用户修订）：所有适用维度 ≥4、无未验证的必要锁、无硬失败才接受；均分仅作汇总，不能抵消单项失败。
硬失败：越过保护区、未授权换身份/商品结构、文字/Logo 错误、未授权构图/灯光改变等任务硬约束破坏。Pixel Lock 需实际保护区比对，目测不能证明逐像素一致。
图形海报额外检查逐字正确和排版，不能因人物项 N/A 而自动通过。洗图额外比较全部冻结字段。
失败只修最低分层，进入 [single-variable-repair](single-variable-repair.md)。
