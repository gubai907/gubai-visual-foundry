# Single-Variable Repair

1. 先查看失败图和相关来源，得到九维评分及证据。无图时只能给条件诊断，不能编分。
2. 从适用且已评分项选择最低分维度；同分优先该任务硬 Lock，其次主要交付对象，再按 quality-gate 表顺序，记录选择理由。未验证项先核实，不凭空排到最低。
3. 在该层选择一个具体可变字段，例如 `prop.scale`、`identity.facial_geometry`、`hand.grip_contact` 或 `skin.texture`，而不是整条 Prompt。
4. 用最后通过的源/版本冻结其余字段；只修改该字段相关指令或局部区域。不得同时加锁、改姿势、换镜头、改景深来修同一个问题。
5. 出图后复查目标及冻结项。若出现回归，不升级为母版；保留原版，从相同单变量范围调整。连续两次无改善时检查来源/工具能力，提出更合适的局部路径，不自动扩大到全图重写。

修复记录：`baseline / score_evidence / lowest_dimension / editable_field / frozen_fields / prompt_delta / result / regression`。

| 失败 | 本轮唯一变化 | 冻结 |
|---|---|---|
| 包过大 | 包相对手部的尺度 | 包款/颜色、身份、衣鞋、姿态、构图、灯光 |
| 人脸漂移 | 指定人脸几何恢复到 A | 身材、衣着、动作、道具、相机、环境 |
| 手与包粘连 | 接触局部的手指分离/握持关系 | 道具结构与尺度、人物身份、全身姿势、光线 |
| 塑料皮肤 | 局部皮肤纹理 | 骨相、肤色范围、妆容、表情、构图与光线 |

若一个物理修复必然涉及局部接触阴影，把它作为同一接触关系字段的必要影响记录；不能由此重打整图灯光。
硬锁失败但最低分为另一层时仍先修最低分，整图保持不通过；不能修好构图后忽略残留身份错误。
