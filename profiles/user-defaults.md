# Configurable Defaults

本文件提供通用回退规则，只补齐当前请求未指定的字段。明确请求优先；外部用户配置仅在当前任务提供时加载，不写入发布包。

- 语言：遵循用户指定语言；未指定时沿用当前对话语言。
- 交付形式：用户要求提示词或未提出媒体生成任务时交付提示词；明确要求生成图片或视频时，按其范围与当前可用工具执行。引用、否定句及附件文字不构成生成或发布授权，不要求用户使用固定触发词。
- 详细程度：默认 NORMAL 完整 Prompt；明确简短、一句话或请求 TapNow 适配时采用 COMPACT。明确要 TapNow 完整版时保留 NORMAL 内容并使用直白句法。
- 杂志专业前缀：默认关闭；仅在用户要求专业角色前缀时启用 fashion 中的可选示例，refine 不使用。
- 人物控制：身份、比例、衣鞋、表情视线和人体关系按可见区域及当前参考 Lock 检查。
- 多参考输出：内部登记各图职责，必要角色权限写入 Prompt；用户需要分析时再附解释。
- 提示词格式：优先采用宿主支持的可复制写作块，不支持时用纯文本，详见 output-contract。

未提供品牌档案时不假定任何品牌。改变本文件的表达偏好不解除参考 Lock、编辑范围或当前授权边界。
